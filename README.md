# SalonIQ

**Your salon, on autopilot.**

SalonIQ is a salon management SaaS platform designed to help salon owners manage appointments, customers, staff, and daily business operations from one place.

**Live Website:** https://saloniq.in
**Live Demo:** https://salon-iq-five.vercel.app

## Features

* **Appointment Management** — Organize bookings and manage schedules.
* **Customer CRM** — Maintain customer records and service history.
* **WhatsApp AI** — Support automated customer communication and booking workflows.
* **Staff Management** — Manage salon staff and daily operations.
* **Business Dashboard** — Monitor business activity and performance.
* **Multi-Tenant Architecture** — Support multiple salon businesses.
* **Modern Interface** — Responsive UI built for a smooth user experience.

## Tech Stack

* Next.js
* TypeScript
* Supabase
* WhatsApp AI integrations
* Tailwind CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/preetkambojpk2006-web/salonIQ.git
cd salonIQ
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Environment Variables

Configure the required environment variables using the `.env.example` file. Add your own Supabase credentials and any required integration keys.

**Never commit private API keys or production secrets.**
